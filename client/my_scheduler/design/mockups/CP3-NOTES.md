The real event markup (frontend `eventContent`) is `.fc-event-main > div > .fc-event-time, .fc-event-title, .conflict-badge` in the time grid and `a.fc-event > div > ...` in month (dayGrid dot events have no `.fc-event-main`). - Month at <=600px: `.fc-daygrid-event .fc-event-time { display: none }`, title `white-space: nowrap; overflow: hidden; text-overflow: ellipsis`, and `.fc-daygrid-event, .fc-daygrid-event > div { min-width: 0; overflow: hidden }` so the ellipsis has a box to clip against. Desktop month unchanged.
- Compact conflict badge: `font-size: 0; gap: 0; padding: 2px 4px` on `.fc .conflict-badge` inside `@container (max-height: 40px)` (half-hour blocks), `@container (max-width: 120px)` (narrow overlapping columns) and month on phones. `font-size: 0` hides the label text node (no component change); the SVG keeps its 14px size and the button keeps its aria-label ("Conflict: overlaps with X..."), so the state is still not color-only (icon + dashed or coral outline).
- Half-hour blocks (`@container (max-height: 40px)`): `.fc-event-main > div` becomes a flex row (time, title, badge) with the badge `flex: none`.
- Keyboard focus: FullCalendar focuses the event `<a>` itself (verified in the browser; there is no tall harness outline) and draws a dark `.fc-event:focus::after` overlay. The overlay is hidden and replaced by `box-shadow: 0 0 0 2px var(--color-bg), 0 0 0 5px var(--color-mint)` plus `z-index: 5`. Time-block events get a variant that keeps their inset light-blue stripe (the stripe rule has higher specificity). Mint on the page is a tested 3:1 pair; the page-colored gap separates the ring from the event fill.
- On-focus full "Title, time" label via `::before { content: attr(title) }`: tried and dropped. The label rendered inside the event's clipped box and overlapped its own text; making it work needs a component (a real tooltip element). The title attribute still gives the native tooltip.
